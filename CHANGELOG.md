## How to read this file

Each release section contains:

- **Added** — new features or capabilities
- **Changed** — changes to existing behaviour
- **Deprecated** — features that will be removed in a future release
- **Removed** — features removed in this release
- **Fixed** — bug fixes
- **Security** — security patches (referenced, not detailed here)

---

## Maintainer note

Update this file with every PR that merges. Do not leave it to the release moment — at that point you will have forgotten half of what changed.

A useful habit: write the changelog entry in the PR description, then paste it here when merging.

For the full release process, see [docs/maintainer/RELEASE_PROCESS.md](./maintainer/RELEASE_PROCESS.md).
